The Birch model

Why the Birch model?

Mechanistic models such as MAK2 (Boggy & Woolf, PLoS ONE 2010) estimate the initial target quantity directly from reaction kinetics, with no standard curve and no efficiency assumption from a threshold. However, MAK2 describes only the start of the reaction, so it must be truncated near the second-derivative maximum and ignores most of the data. Empirical sigmoids (4PL/5PL) fit the whole curve, but their parameters have no physical meaning, so x₀ cannot be read from them in a principled way.

The Birch model has the strengths of both:

  • it is derived from the PCR reaction scheme (primer annealing competing with template re-annealing), so its parameters have a physical meaning;
  • it describes the whole curve, from the exponential phase through the slowdown and up to the plateau, so every cycle informs the fit;
  • it needs just two non-linear parameters (b, tₘ). This is the same number as the 4PL, and one fewer than the 5PL, yet the curve can still be asymmetric.

Derivation

Reaction scheme

SymbolSpecies
Asingle-stranded target DNA (ssDNA, after denaturation)
Bprimer
Sprimed template (ssDNA + annealed primer)
Pdouble-stranded DNA (dsDNA), which is the fluorescent product
Epolymerase

During the annealing/extension step of each cycle, every single strand A has two possible fates:

  1. Productive annealing then extension: A + B → S, then S + E → ES → P + E. The strand is copied, so one new strand is created (and one primer is used up).
  2. Non-productive re-annealing: A + A → P. The strand re-hybridises with its complementary strand, no copy is made, and no primer is used.

Hypotheses

  • H1 – Non-limiting polymerase. E is in excess and extension is fast compared with annealing. S is therefore in quasi-steady state (d[S]/dt ≈ 0) and every primed template is extended within the cycle. Annealing and extension can be lumped into a single step.

  • H2 – Complete denaturation. At the start of each cycle, all target DNA is single-stranded: [A] = n, where n is the number of target strands.

  • H3 – Primers are the limiting resource. Each new strand uses one primer, so [B] = B₀ − (n − n₀). Defining the carrying capacity

    \[K = B_0 + n_0 ,\]

    the free primer pool is simply [B] = K − n. The plateau is reached when the primers are exhausted (n → K).

  • H4 – Kinetic partition. Within an annealing step, a strand's fate is set by the ratio of the two competing rates. These rates are evaluated with the concentrations at the start of the step:

    \[\text{primer annealing: } k_1[A][B], \qquad \text{re-annealing: } k_2[A]^2 .\]

    The fraction of strands that get copied, i.e. the per-cycle efficiency, is therefore

    \[\varphi(n) = \frac{k_1[A][B]}{k_1[A][B] + k_2[A]^2} = \frac{k_1 (K-n)}{k_1 (K-n) + k_2\, n}.\]

  • H5 – Continuous-cycle approximation. The cycle number c is treated as continuous. The mechanistic per-cycle update n_{c+1} = (1 + E_max·φ) n_c is replaced by d ln n / dc = a·φ, where a = ln(1 + E_max). This package assumes perfect doubling at low template (E_max = 1, a = ln 2), as MAK2 does. See Discrete cycles vs continuous time for what this approximation does and does not change.

  • H6 – Fluorescence is proportional to product. After extension, every strand (copied or re-annealed) sits in a duplex, so [P] ∝ n and F = F_bg + F_max · n/K.

From the scheme to the ODE

Combining H4 and H5:

\[\frac{dn}{dc} = a\,n\,\varphi(n) = \frac{a\,k_1\,n\,(K-n)}{k_1 K + (k_2 - k_1)\,n}.\]

Dividing the numerator and denominator by k₁ and setting

\[b = \frac{k_2}{k_1} - 1\]

gives the Birch growth equation (Birch, Ann. Bot. 1999):

\frac{dn}{dc} = \frac{a\,n\,(K-n)}{K + b\,n}

or, for the normalised quantity x = n/K ∈ (0, 1),

\[\frac{dx}{dc} = \frac{a\,x\,(1-x)}{1 + b\,x}.\]

Discrete cycles vs continuous time

PCR runs in discrete cycles, but the Birch model is an ODE. The ODE is autonomous: its right-hand side depends on n only, not on c. Two consequences follow:

  • No discretisation error. Sampled at whole cycles, the ODE solution follows exactly a recursion x_{c+1} = Φ(x_c), where Φ is the solution map over one cycle. Φ is the same for every cycle, so fitting the continuous solution at integer cycles is fitting a genuine cycle-to-cycle model with constant reaction conditions.
  • Changing a only rescales time. At low template, Φ(x) → (1 + E_max)·x exactly, so a = ln(1 + E_max) reproduces the per-cycle efficiency of the exponential phase with no approximation.

However, Φ is not the mechanistic update x + E_max·φ(x)·x, and no time rescaling can make the two equal, because the required factor changes along the curve. For the logistic case (b = 0, a = ln 2), Φ(x) = 2x/(1 + x) (the Beverton–Holt map). Its per-cycle efficiency is (1 − x)/(1 + x), compared with φ = 1 − x from the kinetic partition (1/3 vs 1/2 at half-plateau). The two agree exactly at the start (efficiency E_max) and at the plateau (efficiency 0), and differ in between.

The rate must set the time scale. The same reasoning explains how MAK2Model is implemented. Instead of iterating the MAK2 recursion x_{c+1} = x_c + ln(1 + x_c), it uses the implicit solution Ei(z) − Ei(z₀) = ln 2 · c (with z = ln(1 + x)) of the ODE dx/dc = ln 2 · ln(1 + x), which is convenient for sensitivity analysis. The ln 2 factor matters. Without it, the ODE grows by e per cycle in the exponential phase instead of 2. The fitted x₀ then scales as x₀^(1/ln 2) ≈ x₀^1.44, which distorts fold changes, and it is a power law, not a constant rescaling. With it, the ODE and the recursion agree in the exponential phase, and x₀ differs from the recursion estimate only by a constant factor (≈ 0.55), which cancels in fold changes.

The Birch curve is therefore an exact, cycle-invariant model in its own right. The approximation lies only in its mechanistic reading: b = k₂/k₁ − 1 is a faithful summary of the competition between primer annealing and re-annealing, not an exact estimate of the rate-constant ratio.

What the parameters mean

  • K = B₀ + n₀: the plateau, set by the primer supply. Since the model is fitted on x = n/K and the fluorescence scale is a linear parameter, K never has to be known.
  • a = ln(1 + E_max): the growth rate in early cycles, fixed to ln 2. It sets the time scale and makes the early per-cycle growth exactly 1 + E_max.
  • b = k₂/k₁ − 1 > −1: the competition parameter, which compares re-annealing with primer annealing. Because k₂ ≥ 0, b > −1; the code enforces this through b = expm1(p).
    • b → −1 (no re-annealing): dx/dc = a·x. The curve is purely exponential until the primers run out, then breaks sharply into the plateau.
    • b = 0 (k₁ = k₂): the classical logistic model, a symmetric sigmoid.
    • b > 0 (re-annealing is faster than priming): as product builds up, re-annealing increasingly wins over priming. Efficiency drops before primers are exhausted, which gives the long, asymmetric approach to the plateau seen in real qPCR curves.

The b·x term in the denominator is a density-dependent inhibition. It is the mechanistic counterpart of the empirical asymmetry factor ν in the Richards model.

Closed-form (implicit) solution

The variables separate. With the partial fractions (1 + b x)/(x(1 − x)) = 1/x + (1 + b)/(1 − x):

\[\ln x - (1+b)\ln(1-x) = a\,c + C .\]

The constant is fixed by x(tₘ) = 1/2, so that tₘ is the half-amplification cycle. With a = ln 2, this is the equation solved for each cycle in src/models.jl:

\[\ln x - (1+b)\ln(1-x) = \ln 2\,(c - t_m + b).\]

For each cycle, x(c) is computed with a safeguarded Newton solver (newtsafe_rootfinding). The Jacobian comes from implicit differentiation of the same relation.

Derived quantities

  • Initial quantity x₀ = n₀/K, obtained by solving the implicit equation at c = 0 (get_x0, get_logx0). It is the ratio of initial template strands to the total primer + template pool, and it is directly comparable between wells that share the same master mix.
  • Inflection point: x_i = 1 / (1 + √(1 + b)). This is 1/2 for the logistic case and lower for b > 0.
  • Cy₀ (Guescini et al., BMC Bioinformatics 2008): the intersection of the tangent at the inflection point with the baseline (get_cy0).
