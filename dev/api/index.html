qPCRModels.qPCRModels — Module
qPCRModels

qPCRModels is a Julia package for non-linear least squares modeling and analysis of real-time quantitative PCR (qPCR) fluorescence amplification curves.

Key Features

  • Model Implementations:
    • BirchModel: Mechanistic logistic model accounting for reaction kinetics.
    • LogisticModel: Standard 4-parameter logistic curve model.
    • RichardsModel: 5-parameter generalized logistic model with asymmetry factor ν.
    • MAK2Model: Mechanistic mass-action kinetic qPCR model.
  • Solvers & Root-finding:
    • LevenbergMarquardt!: Dampened non-linear least squares optimization.
    • newtsafe_rootfinding: Safe Newton-Raphson rootfinder with bisection fallback.
  • Diagnostics & Metrics:
    • cyclethreshold, hac, sdm: Threshold, half-amplification cycle, and second-derivative maximum estimators.
    • isnoise: Noise and non-amplification detection heuristic based on Median Absolute Deviation.
    • AICc, chisq, reducedchisq, get_x0, get_logx0: Model quality criteria and initial concentration estimators.
    • get_stderrors: Standard errors of the fitted parameters and of ln(x₀).
  • Absolute quantification:
    • calibration, quantify: Robust standard curve from wells of known quantity, and its use on new samples.
  • Built-in Datasets:
    • qpcRDataset, load_qpcR_dataset: Access to benchmark qPCR datasets (e.g. batsch1, boggy, testdat).

qPCRModels.BirchModel — Type
BirchModel{T} <: NonLinearLeastSquare

Mechanistic logistic qPCR model based on the Birch model kinetics for fluorescence growth curves.

Uses Variable Projection (VarPro) to decouple non-linear rate/position parameters from linear scale and offset parameters.

Fields

  • rawdata::Vector{T}: Original unscaled input fluorescence vector.
  • data::Vector{Float64}: Scaled data normalized by standard deviation.
  • σ::Float64: Standard deviation of the raw dataset.
  • params::Vector{Float64}: Non-linear model parameters [params[1], tₘ].
  • linearparams::Vector{Float64}: Linear scale and offset parameters.
  • chisq::Float64: Chi-squared merit function result after fitting.
  • fitted::Bool: true if model fitting has been executed.
  • converged::Bool: true if model optimization converged.
  • noamp::Bool: true if input curve is detected as noise.
  • xmat::Matrix{Float64}: Work buffer matrix for Variable Projection.

Constructor

m = BirchModel(data; detection_threshold = 5.0)

Trailing missing cycles (NaN) are dropped; missing values before the last measured cycle throw an ArgumentError.

qPCRModels.CalibrationCurve — Type
CalibrationCurve

Standard curve log₁₀ x₀ = intercept + slope · log₁₀ q relating the model estimate x₀ to a known template quantity q (e.g. copies), fitted by calibration. Use quantify to convert the x₀ of a new sample into an absolute quantity.

Fields

  • slope, intercept: fitted coefficients (slope = 1 when it is fixed).
  • slope_se, intercept_se: approximate standard errors (slope_se = 0 when the slope is fixed).
  • r2: coefficient of determination of the used points.
  • weights::Vector{Float64}: final weight of each input point (bisquare weights in [0, 1] if robust, 0 for rejected or unused points).
  • used::BitVector: inputs with a finite x₀ (and, for models, a converged fit).
  • robust::Bool, fixed_slope::Bool: fitting options.
  • converged::Bool: true if the robust iterations converged.

NonLinearLeastSquare

Abstract base type for all non-linear least squares qPCR amplification models in qPCRModels.

Subtypes must implement parameter transformations (get_params), linear variable projection parameter computation (get_linearparams!), and the curve with its sensitivities to the non-linear parameters (_curve_jacobian!, used by the generic residualsJacobian!).

qPCRModels.LevenbergMarquardt! — Method
LevenbergMarquardt!(nlm::NonLinearLeastSquare; kwargs...)

Fit parameters of a non-linear least squares model nlm using the Levenberg-Marquardt optimization algorithm with adaptive damping.

Arguments

  • nlm::NonLinearLeastSquare: Target qPCR non-linear model.

Keyword Arguments

  • LMtol::Real = 1e-8: Convergence tolerance on gradient norm.
  • LMtol_chisq::Real = 10 * eps(): Tolerance for relative change in χ² merit function.
  • LMtol_step::Real = 10 * eps(): Tolerance on step size Δ.
  • Ndone::Int = 10: Number of consecutive small steps required for termination.
  • LMmaxiter::Int = 1_000: Maximum allowed iterations.
  • λinit::Real = 1e-2: Initial damping factor multiplier.
  • λdec::Real = 2: Factor by which damping λ is divided upon successful step.
  • λinc::Real = 3: Factor by which damping λ is multiplied upon failed step.
  • min_damping::Real = 10 * eps(): Lower limit for damping parameter.
  • max_dampening::Real = 0.1 * inv(eps()): Upper limit for damping parameter.

Returns

  • (chisq::Float64, converged::Bool): Final chi-squared sum of squared residuals and convergence status flag.

qPCRModels.calibration — Method
calibration(quantity, models; robust = true, fixed_slope = false)
calibration(quantity, x0; robust = true, fixed_slope = false)

Fit the standard curve log₁₀ x₀ = intercept + slope · log₁₀ q from standards of known quantity q.

The second argument is either a vector of fitted models (their get_logx0 is used, and models that did not converge are left out) or a vector of x₀ values (non-positive or non-finite values are left out).

For a mechanistic model, x₀ is proportional to the template, so the slope should be close to 1: a slope far from 1 points to a biased x₀. With fixed_slope = true the slope is set to 1 and only the intercept is fitted.

With robust = true (default) the line is fitted with Tukey's bisquare weights, so that outlier wells are down-weighted (see the weights field); otherwise by ordinary least squares. Standard errors come from the final weighted least-squares step and are approximate for the robust fit.

Example

standards = [BirchModel(y) for y in standard_curves] # wells with 10⁵, 10⁴, 10³ and 10² copies
foreach(fit!, standards)
cal = calibration([1e5, 1e4, 1e3, 1e2], standards)
sample = BirchModel(sample_curve)
fit!(sample)
quantify(cal, sample) # copies in the sample well

qPCRModels.get_stderrors — Method
get_stderrors(nlm::NonLinearLeastSquare; kwargs...)

Standard errors of a fitted model, as a NamedTuple: the non-linear parameters returned by get_params (none for MAK2Model), the baseline F_bg and scale F_max (raw fluorescence units) and logx0 (of get_logx0).

They come from the Gauss–Newton covariance s² (JᵀJ)⁻¹ at the optimum, where J is the Jacobian of the model in all its parameters and s² = χ²/(n - k), and are propagated to the reported quantities by the delta method. All values are NaN when the model is not fitted.

qPCRModels.isnoise — Method
isnoise(x; detection_threshold::Real = 5.0)

Determine whether fluorescence curve x represents background noise without true amplification.

Compares the total observed range max(x) - min(x) against expected noise level from Gaussian extreme value theory.

Arguments

  • x: Vector of cycle fluorescence data.
  • detection_threshold::Real: Multiplier for noise threshold (default: 5.0).

Returns

  • true if curve is classified as noise (no amplification); false if real amplification is present.

qPCRModels.newtsafe_rootfinding — Method
newtsafe_rootfinding(f, df, a, b; x₀ = (a + b) / 2, RFtol = 10 * eps(), RFmaxiter = 100, offset = 0.0)

Globally convergent root-finding solver combining Newton-Raphson iterations with bisection bounds. Code adapted from Press, W. H. (2007), Numerical recipes 3rd edition: The art of scientific computing, p460-461.

Solves f(x) + offset = 0 within bracket [a, b]. Automatically reverts to bisection step if a Newton iteration jumps outside bounds or fails to converge rapidly.

Arguments

  • f: Function returning scalar evaluation f(x).
  • df: Derivative function f'(x).
  • a::Real, b::Real: Search bracket bounds satisfying (f(a)+offset)*(f(b)+offset) <= 0.

Keyword Arguments

  • x₀::Real: Initial starting guess (defaults to interval midpoint (a + b)/2).
  • RFtol::Real: Desired tolerance on root position (absolute for |x| ≤ 1, relative for |x| > 1); the search always stops once a step is within one ulp of x.
  • RFmaxiter::Int: Maximum allowed iterations (default: 100).
  • offset::Real: Target offset value (default: 0.0).

Returns

  • (x::Float64, converged::Bool): Estimated root location and boolean success flag.
